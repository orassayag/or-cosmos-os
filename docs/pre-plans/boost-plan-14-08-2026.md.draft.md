## Scope Challenge

**Scope challenge:** this boost plan is a bag of independent fixes, not one feature — it splits cleanly into two demonstrable increments. **(1) Harden the nightly agent** — the six 🔴 security/correctness fixes (I1–I6): write-surface enforcement, no-drift baseline safety, prompt-injection hardening, secret denylist + symlink guard, token-off-command-line, read-only clone credential. This is the increment that actually matters, because the drift pipeline is an automated AI agent holding repo credentials — every High is a real exposure. **(2) Correctness & DX polish** — the mediums (I7–I11) plus the held-back items. Recommended because increment 1 is a coherent, submittable security pass on its own; landing it first means the agent is safe before you spend time on pricing tables and test scaffolding. Accept the split (I treat I1–I6 as the plan's scope, park the rest) or wave it off — your call.
